# reader

Консольная читалка электронных книг: TXT, EPUB, FB2, MOBI, AZW, AZW3, PDF, DJVU, DOCX, DOC, HTML, Markdown, RTF. Минималистичный тёмный интерфейс, библиотека в SQLite, закладки и прогресс чтения.

## Возможности

- **Файловый менеджер встроен**: клавиша `i` открывает браузер файлов — выбираете книгу и она сразу открывается
- **Форматы**: TXT (автодетект кодировки), EPUB, FB2 (в т.ч. `.fb2.zip`), HTML/HTM, Markdown, RTF, DOCX — без доп. зависимостей; PDF — через pypdf; MOBI/AZW/AZW3 — собственный парсер PalmDB; DJVU — через djvutxt (djvulibre); DOC — через LibreOffice или antiword
- **Кэш парсинга**: разобранные книги хранятся в SQLite — повторные открытия не перечитывают файл (важно для PDF/DJVU/DOC)
- **Библиотека**: поиск, сортировка, процент прочитанного, автосканирование `~/Books`; колонка «⚑» — сколько закладок в книге
- **Чтение**: постраничный рендер под размер терминала, навигация по главам, закладки, ширина текста; при открытии читаемой книги строка, где остановились, подсвечивается на секунду
- **Чистые заголовки глав**: маркеры (`#`, `##`, `§`) и нумерация (`1.`) убираются автоматически, название главы — `─── Название ───` по центру
- **Закладки с заметками**: `s` — добавить, `e` в списке — своя заметка («стр. 1136 · Jcc — Jump if Condition Is Met»); в таблице библиотеки вместо авторов — «⚑ число · последняя заметка»
- **Полки**: `S` — зайти на полку (там лежат только положенные книги), `p` — положить книгу на полку, `d` на полке — снять; книга может лежать на нескольких полках
- **Таймер чтения**: `t` — старт/пауза/сброс, длительность настраивается (15–90 мин, по умолчанию 30), остаток в статус-баре, уведомление по истечении
- **Центрирование**: библиотека — таблица по центру (до 110 колонок); под логотипом — блок последней прочитанной книги (название, автор, % — всё по центру, `g` или клик продолжить чтение); текст книги — колонка по центру экрана
- **Прогресс** сохраняется автоматически при листании

## Установка

Нужен Python 3.11+ и [uv](https://docs.astral.sh/uv/):

```bash
uv tool install git+https://github.com/saochinomi/reader.git
```

или локально:

```bash
uv tool install .          # из каталога проекта
pipx install .             # альтернатива через pipx
pip install --user .       # или через pip
```

После установки добавьте `~/.local/bin` в PATH (uv обычно делает это сам):

```bash
uv tool update-shell       # автоматически обновит конфиги шеллов
```

Если `reader` всё ещё не находится — добавьте вручную в `~/.bashrc` (или `~/.zshrc`):

```bash
export PATH="$HOME/.local/bin:$PATH"
```

## Использование

```bash
reader                # открыть библиотеку
reader book.epub      # сразу открыть книгу
reader ~/books        # импортировать папку и показать библиотеку
reader --import ~/books   # импортировать папку без запуска интерфейса
```

Проще всего: положите книги в `~/Books` — при каждом запуске папка сканируется автоматически.

## Управление

| Клавиша | Действие |
|---|---|
| `Tab` | Переключиться на следующую открытую книгу (вкладка) |
| `i` | Добавить книгу — файловый менеджер |
| `Enter` | Открыть выбранную книгу |
| `/` | Поиск |
| `s` | Сортировка (название / автор / год) |
| `c` | Акцентный цвет (зелёный / синий / фиолетовый / …) |
| `t` | Таймер чтения (30 мин по умолчанию) |
| `u` | Пересканировать `~/Books` |
| `d` | Удалить книгу из библиотеки (на полке — снять с полки) |
| `S` | Полки: зайти на полку / создать / удалить |
| `p` | Положить выбранную книгу на полку |
| `B` | Закладки всех книг — открыть прямо на закладке |
| `?` | Помощь |
| `q` | Выход |

Вверху — баннер **READER**, под ним вкладки недавно открытых книг (клик — открыть, `+` — добавить), внизу — статус-бар и панель клавиш с иконками (по центру).

### В файловом менеджере

| Клавиша | Действие |
|---|---|
| `↑/↓` | Навигация |
| `Enter` | Войти в папку / открыть книгу |
| `h` | Домашняя папка |
| `b` | `~/Books` |
| `l` | Последняя папка |
| `Esc` | Назад |

### В читалке

| Клавиша | Действие |
|---|---|
| `j` / `k` | Следующая / предыдущая страница |
| `n` / `p` | Следующая / предыдущая глава |
| `s` | Добавить закладку |
| `[` / `]` | Предыдущая / следующая закладка |
| `b` | Список закладок (`e` — заметка к закладке) |
| `f` | Ширина текста |
| `c` | Акцентный цвет |
| `t` | Таймер чтения |
| `?` | Помощь |
| `Esc` | Назад в библиотеку |

Внизу — статус-бар (режим READ, название, глава, страница, прогресс-бар) и панель клавиш с иконками.
