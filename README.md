# reader

Консольная читалка электронных книг: TXT, EPUB, FB2. Минималистичный тёмный интерфейс, библиотека в SQLite, закладки и прогресс чтения.

## Возможности

- **Файловый менеджер встроен**: клавиша `i` открывает браузер файлов — выбираете книгу и она сразу открывается
- **Форматы**: TXT (автодетект кодировки), EPUB, FB2 (в т.ч. `.fb2.zip`)
- **Библиотека**: поиск, сортировка, процент прочитанного, автосканирование `~/Books`
- **Чтение**: постраничный рендер под размер терминала, навигация по главам, закладки, ширина текста
- **Прогресс** сохраняется автоматически при листании

## Установка

Нужен Python 3.11+ и [uv](https://docs.astral.sh/uv/):

```bash
uv tool install git+https://github.com/saochinomi/reader.git
```

или локально:

```bash
uv tool install .          # из каталога проекта
pipx install .             # альтернатива через pipx
pip install --user .       # или через pip
```

## Использование

```bash
reader                # открыть библиотеку
reader book.epub      # сразу открыть книгу
reader ~/books        # импортировать папку и показать библиотеку
reader --import ~/books   # импортировать папку без запуска интерфейса
```

Проще всего: положите книги в `~/Books` — при каждом запуске папка сканируется автоматически.

## Управление

| Клавиша | Действие |
|---|---|
| `i` | Добавить книгу — файловый менеджер |
| `Enter` | Открыть выбранную книгу |
| `/` | Поиск |
| `s` | Сортировка (название / автор / год) |
| `u` | Пересканировать `~/Books` |
| `d` | Удалить книгу из библиотеки |
| `q` | Выход |

### В файловом менеджере

| Клавиша | Действие |
|---|---|
| `↑/↓` | Навигация |
| `Enter` | Войти в папку / открыть книгу |
| `h` | Домашняя папка |
| `b` | `~/Books` |
| `l` | Последняя папка |
| `Esc` | Назад |

### В читалке

| Клавиша | Действие |
|---|---|
| `j` / `k` | Следующая / предыдущая страница |
| `n` / `p` | Следующая / предыдущая глава |
| `s` | Добавить закладку |
| `b` | Список закладок |
| `f` | Ширина текста |
| `Esc` | Назад в библиотеку |
