# reader

Консольная читалка книг. Работает с TXT, EPUB, FB2, MOBI, AZW, AZW3, PDF, DJVU, DOCX, DOC, HTML, Markdown и RTF. Тёмный минималистичный интерфейс, библиотека хранится в SQLite, есть закладки, заметки к тексту и прогресс чтения.

## Что умеет

Библиотека с поиском и сортировкой, автосканирование `~/Books` при запуске, встроенный файловый менеджер (клавиша `i`). Справа от логотипа карточка последней книги, по центру таблица с прогрессом чтения и количеством закладок.

В читалке постраничный рендер под размер окна, переключение ширины текста, навигация по главам. Прогресс сохраняется сам. Если книга уже читалась, при открытии строка, на которой вы остановились, подсвечивается на секунду.

В тексте можно выделять фрагменты мышью: зажать левую кнопку на тексте, протянуть, отпустить. Сразу появится окно с пятью цветами и пунктом «Копировать текст». Цвет сохраняет выделение как заметку, потом к ней можно вернуться с экрана заметок (клавиша `H`): там список книг, внутри каждой фрагменты по порядку, по Enter открывается книга ровно на этом месте.

Ещё есть закладки с собственными заметками, полки для книг, таймер чтения, смена акцентного цвета. Заголовки глав очищаются от маркеров вроде `#`, `##`, `§` и нумерации, показываются по центру между двумя тире.

Форматы без лишних зависимостей разбираются сами: TXT (кодировка определяется автоматически), EPUB, FB2 (в том числе `.fb2.zip`), HTML, Markdown, RTF, DOCX, MOBI и AZW (свой PalmDB-парсер). PDF открывается через pypdf, DJVU через djvutxt, DOC через LibreOffice или antiword. Разобранные книги кэшируются в SQLite, поэтому повторное открытие не перечитывает файл.

## Установка

Нужен Python 3.11+ и [uv](https://docs.astral.sh/uv/):

```bash
uv tool install git+https://github.com/saochinomi/reader.git
```

Или из каталога проекта:

```bash
uv tool install .
```

После установки `uv` обычно сам прописывает `~/.local/bin` в PATH. Если нет, добавьте вручную:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

## Запуск

```bash
reader                # библиотека
reader book.epub      # сразу открыть книгу
reader ~/books        # импортировать папку и показать библиотеку
reader --import ~/books   # только импортировать, без интерфейса
```

Проще всего складывать книги в `~/Books`: при каждом запуске папка сканируется сама. Сначала показывается заставка с логотипом, Enter вводит в библиотеку (или сразу в книгу, если она передана аргументом).

## Клавиши

Библиотека:

| Клавиша | Действие |
|---|---|
| `Tab` | следующая открытая книга |
| `i` | добавить книгу, файловый менеджер |
| `Enter` | открыть выбранную |
| `/` | поиск |
| `s` | сортировка: название, автор, год |
| `g` | продолжить чтение последней книги |
| `d` | удалить (на полке снимает с полки) |
| `S` | полки |
| `p` | положить книгу на полку |
| `B` | закладки всех книг |
| `H` | заметки по книгам |
| `c` | цвет, `t` таймер, `u` пересканировать, `?` помощь, `q` выход |

Файловый менеджер: `↑`/`↓` навигация, `Enter` войти или открыть, `h` домой, `b` в `~/Books`, `l` последняя папка, `Esc` назад.

Читалка:

| Клавиша | Действие |
|---|---|
| `j` / `k` | следующая / предыдущая страница |
| `n` / `p` | следующая / предыдущая глава |
| `s` | закладка |
| `[` / `]` | перейти к предыдущей / следующей закладке |
| `b` | список закладок, `e` заметка к закладке |
| `H` | заметки этой книги |
| `f` | ширина текста |
| `c` | цвет, `t` таймер, `?` помощь |
| `Esc` | назад |

Подсказка по всем клавишам есть прямо в интерфейсе: слева вертикальная панель с иконками, внизу тонкий статус-бар с прогрессом.
